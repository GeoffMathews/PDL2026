Comparing Temperatures of Dense Objects

Read the following text and watch the video to review how to use the spectra of dense objects to compare their temperatures.

We can use the peak of the spectrums of two dense objects to compare their temperatures.

  1. Find the peak of each spectrum
  2. If reading a graph, drop down to the X-axis to read the wavelength of the peak
  3. Compare that wavelengths of the peaks.
    • the object that peaks at a longer wavelength (a larger number for wavelength) is cooler (a smaller number for temperature)
    • the object that peaks at a shorter wavelength (a smaller number for wavelength) is hotter (a larger number for temperature)
